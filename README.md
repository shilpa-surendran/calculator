# Python Calculator

A simple, production-ready calculator written in Python.

## Features

- Addition and subtraction of two numbers.
- Handles integers and floats.
- Robust error handling for non-numeric inputs.
- A separate module for operations.

## Usage

To use the calculator, run the `calculator.py` script from your terminal:

```bash
python calculator.py
```

You will be prompted to select an operation and then enter two numbers. The script will then print the result.

## Testing

To run the unit tests, execute the `test_calculator.py` script:

```bash
python -m unittest test_calculator.py
```

This will run all the tests and provide a report of the results.
